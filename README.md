# 月老事務所｜網頁原始碼

## 開啟方式

- 直接開啟 `index.html`；請保留同一資料夾內的 `styles.css`、`app.js`、`fonts.css` 與 `fonts/`。
- 也可開啟另外提供的「月老事務所.html」，它已把樣式與程式整合在單一檔案。
- 網頁不依賴 Tailwind 或前端框架。若要上線，將原始碼資料夾的所有內容放到同一網站目錄。

## 本版功能

- 米白紙色、淡粉包裝示意、墨灰與深橄欖字色，無紅色字體。
- 今日良緣：依台北日期每日固定一張；包含短籤、生活提醒、今日色彩與小行動，可複製。內容為日常靈感，不是未來預測。
- 商品分類、關鍵字搜尋、價格排序與商品詳情。
- 購物車加減數量、移除商品、保存至目前瀏覽器；單款上限 99 件。
- 超商取貨付款 NT$ 60 運費，正修科技大學面交現金付款免運費。
- 收件資料驗證、結帳品項與金額明細、複製明細。
- 訂單請求送出後關閉結帳視窗，原頁顯示待確認提示與明細；沒有跳頁。
- 同一分頁的相同訂單避免重複傳送，傳送中禁止重複操作。
- 3D 盲盒：可拖曳拉條，或用按鈕、鍵盤 Enter 開箱；可重置及暫停旋轉。
- 心願繪馬：最多 12 張、每張 80 字，可移除；只保存在目前瀏覽器。
- 常見問題、手機導覽、鍵盤對話框操作、減少動畫偏好支援。
- 沒有商品收藏功能。

## 修改位置

- 商品名稱／金額／說明：`app.js` 的 `products`。
- 今日良緣籤文：`app.js` 的 `fortunes`。
- 字色／背景／間距：`styles.css` 的 `:root` 與各區塊。
- 品牌文字與常見問題：`index.html`。
- Google Apps Script：`app.js` 的 `SCRIPT_URL`。

## Google 試算表接單：尚未驗證

沿用原先提供的 Apps Script `/exec` URL，並未存取或修改 Google 後端，也沒有向真實端點提交測試訂單。

前端以 URL 編碼表單 POST 傳送下列資料：

`action=order`、`orderId`、`name`、`phone`、`store`、`paymentMethod`、`subtotal`、`shipping`、`total`、`items`。

原有欄位 `name`、`phone`、`store`、`total`、`items` 保留；`store` 在面交時包含正修科技大學與現金付款說明。新欄位若要寫入試算表，後端也必須對應。

`no-cors` 回應無法讓前端讀取真正的 HTTP 結果或確認 `appendRow` 成功。因此本版只顯示「訂單請求已送出，待店家確認」，不宣稱訂單成立、付款成功或試算表已有資料。購物車不會因此清空，明細會保留在該分頁的工作階段中。

要修好實際試算表接單，仍需要原 Apps Script 的 `Code.gs`、部署設定及執行錯誤紀錄。應確認後端接受 `e.parameter` 表單欄位、指向正確試算表／工作表，並部署了正確版本。若要在前端確認真正收單，需進一步改成可驗證的後端回應流程。

商品價格、數量與金額仍應在正式後端再次驗證；前端資料不可作為後端唯一計價依據。

## 本機儲存與限制

- 購物車、今日小籤、心願使用 localStorage；清除瀏覽資料、無痕模式或更換裝置可能導致資料不保留。
- 姓名與手機不保存至 localStorage。待確認訂單明細保留於 sessionStorage；包含商品、金額、取貨方式及填寫的超商門市，不含姓名、手機。
- 商品圖片是 CSS 包裝／底座示意，不是商品實拍。上線前可換成自己的照片。
- 線上拆盒只供互動體驗，不決定實際出貨款式。
- 月老靈籤保留原先外部網站連結，能否載入由該網站決定。
- 使用現代瀏覽器；自動複製不可用時，會提供可選取的文字視窗。

## 隨附字型

隨附 Noto Serif TC 與 Noto Sans TC 的文字子集，使用 SIL Open Font License；授權全文位於 `fonts/`。不需依賴外部字型服務。新加入且不在子集中的文字會使用系統字型。

## 驗證

已在 Chromium 檢查 1440px 桌面、768px 平板及 390px／320px 手機寬度，並測試分類、搜尋、排序、詳情、購物車保存、兩種運費、欄位驗證、網路失敗、送出後關閉、重複訂單防護、今日小籤跨台北午夜更新、心願內容安全顯示與再次開箱。測試訂單請求全部攔截模擬，未送到真實 Google 試算表。
